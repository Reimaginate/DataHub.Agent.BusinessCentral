# DataHub Agent for Business Central 1.0.0-beta.3

This beta refreshes the dependency baseline without changing the Business
Central agent's public API or reference workflow.

## Packages

- `Reimaginate.DataHub.Agent.BusinessCentral.Abstractions`
- `Reimaginate.DataHub.Agent.BusinessCentral`
- `Reimaginate.DataHub.Agent.TestFramework.BusinessCentral`

All three packages are versioned and released together.

## Changes

- Updates DataHub and Core Agent dependencies to 1.4.1.
- Updates Microsoft.Extensions dependencies to the .NET 10.0.11 servicing
  release, Microsoft.Azure.Cosmos to 3.62.1 and Testcontainers dependencies to
  4.14.0.
- Retains the existing sample configuration, mappings, processing commands and
  safety gates from beta.2.

## Upgrade notes

Update all three Business Central package references to `1.0.0-beta.3`. No
configuration or code migration is required from beta.2.

## Beta limitations

- Public APIs and configuration may still change before version 1.0.
- The sample models and mappings are examples, not a canonical business schema.
- Keep write execution disabled until validation and read-only smoke checks pass.
