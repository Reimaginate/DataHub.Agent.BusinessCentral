# Reimaginate.DataHub.Agent.TestFramework.BusinessCentral

Business Central Scenario Builder helpers for explicit and scheduled merge/sync,
batch outcomes, tracking and marker inspection, deterministic HTTP failure tests,
and optional sandbox integration hosting.

Sandbox writes are disabled unless their entity-family gates are explicitly
enabled. Store tenant credentials outside source control and use an isolated
Business Central company. The public repository includes a credential-free
reference solution; the tenant-specific live validation suite remains private.
